# AGENTS.md

This file provides guidance to Pegg when working with code in this repository.

## Project Overview

Pegg is a provider-agnostic AI coding agent written in Go. It runs as an interactive terminal application, a headless CLI, an HTTP API server, an Agent Client Protocol (ACP) server, or as an embeddable Go SDK. The agent can read and edit files, run shell commands, search the web, manage todos, delegate work to subagents, load skills, follow project rules, and talk to MCP and language servers — all inside a sandboxed workspace.

## Repository Structure

- `cmd/pegg/` - Main binary entry point
- `internal/` - Core packages (agent, llm, tools, skills, session, etc.)
- `docs/` - Documentation (system, SDK, plugin guides)
- `pkg/sdk/` - Embeddable Go SDK
- `.pegg/` - Project-specific config, plans, and subagent state
- `.github/workflows/` - CI/CD pipelines (test, fmt, vet, release)

## Code Style & Conventions

- **Formatting**: `gofmt` (enforced by `make fmt`)
- **Linting**: `golangci-lint` (enforced by `make lint`)
- **Testing**: `go test -v ./...`
- **Naming**: Standard Go conventions (PascalCase for exports, camelCase for locals)
- **Architecture**: Event-driven with hooks; agents communicate via event bus
- **Error Handling**: Domain-driven typed errors (e.g., `ErrProviderRateLimit`)

## Architecture Notes

```
┌─────────────────────────────────────────────────────────┐
│                    CLI / TUI Layer                       │
├─────────────────────────────────────────────────────────┤
│                    Event Bus (Hooks)                     │
├─────────────┬─────────────┬─────────────┬───────────────┤
│   Agent     │   LLM       │   Tools     │   Skills      │
│  Framework  │  Providers  │  (Bash,     │  (Dynamic     │
│  (Orch,     │  (OpenAI,   │   File,     │   Engine)     │
│   Sub-agents)│  Claude,   │   Web,      │               │
│             │   Gemini)   │   LSP/MCP)  │               │
├─────────────┴─────────────┴─────────────┴───────────────┤
│              Session DB (SQLite) + Context Manager       │
└─────────────────────────────────────────────────────────┘
```

**Major Components:**
- **Agent System** (`internal/agent/`): Orchestrator, Explorer, Planner, Developer sub-agents with middleware and hooks
- **LLM Layer** (`internal/llm/`): Provider-agnostic interface with drivers for OpenAI, Anthropic, Google; circuit breakers and rate limit fallbacks
- **Decision Layer** (`internal/decision/`): Decision-model interface (noul/choice/score) with providers; e.g. JEV via OpenRouter `/api/alpha/decisions`, reused by the permission judge and the smart router
- **Smart Router** (`internal/router/`): Per-task model selection via decision/LLM fallback; registers an agent `OnModelResolve` system hook that picks models for the orchestrator and subagents at run start, uniformly across CLI, TUI, SDK, and servers
- **Tools** (`internal/tools/`): Bash, file operations, web search/fetch, LSP/MCP integration
- **Skill Engine** (`internal/skill/`): Dynamic skill loading with frontmatter metadata
- **Session Management** (`internal/session/`): SQLite-based persistence with forking and replay
- **TUI** (`internal/tui/`): tcell-based interface with chat viewport, command palette, agent graph view

## Testing Strategy

- **Unit Tests**: `go test -v ./...` (all packages)
- **Integration Tests**: `internal/llm/module_integration_test.go`
- **Test Files**: `*_test.go` in each package
- **CI**: GitHub Actions (implied by `.github/` dir)
- **Coverage**: `coverage.out` generated by tests

## Security & Compliance

- **Secret Redaction**: Middleware auto-detects and redacts API keys/JWTs before LLM calls
- **Filesystem Security**: Custom VFS respects `.gitignore`/`.peggignore`, blocks directory escape
- **Permissions**: Stored in `.pegg/` (project) and `~/.pegg/` (global); prompts user for denied actions
- **Judge LLM**: Pre-execution validation for sensitive tools (e.g., bash)
- **Dependencies**: `go.mod` with pinned versions; `goreleaser` for cross-platform builds

## Agent Guardrails

- **Files Never Touched**: `.pegg/` config files, `~/.pegg/` global config, `.env` secrets
- **Required Reviews**: All changes to `internal/agent/`, `internal/llm/` require human review
- **Rate Limits**: Provider circuit breakers enforce rate limits; fallback to secondary providers
- **Context Limits**: Compacter agent summarizes when context window fills; deep compaction available
- **Emergency Stop**: `ESC` twice halts orchestrator and all sub-agents

## Extensibility Hooks

- **Hook System**: WordPress-style filters/actions throughout codebase (see `internal/agent/hooks.go`)
- **Plugin Directory**: `~/.pegg/plugins/` for global plugins
- **Dynamic Skills**: Agents can create/save skills under `.pegg/skills/`
- **Provider Registration**: New LLM providers added via CLI or config
- **MCP/LSP Integration**: Remote/local servers defined in `pegg.json` or global config
